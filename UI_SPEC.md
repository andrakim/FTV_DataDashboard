# FTV — модули анализа эфира

## Основной сценарий

Тенденция эфира → выбрать даты, кнопками Пн–Пт или отдельные дни, время (например 18:00–19:00), канал и при необходимости программу → сравнить исходные фрагменты графиков рядом.

Основной экран — исходная длинная картинка из Excel. Конструктор графиков, постоянная боковая навигация, боковые фильтры и инспектор убраны. Все основные настройки находятся в компактной горизонтальной панели. Данные программы открываются в диалоге по нажатию.

## Модули

1. **Тенденция эфира.** До пяти дат рядом, единое окно времени, синхронная линия курсора, исходная шкала доли над каждой датой. Переключение недель/страниц дат и увеличение картинки. Выбранная программа выделена рамкой; контекст линии в выбранном часе сохраняется. Повторы не объединяются. Клик по картинке открывает программу в соответствующий момент, без вычисления метрики из пикселя.
2. **Программы.** Простая таблица выходов по тем же датам, дням недели и времени. Включаются программы, пересекающие окно, даже если начались раньше. Есть средняя доля, средние зрители при наличии демографии, точность источника, вход/выход и одновременный эфир конкурентов в диалоге. CSV содержит всю выборку и параметры.
3. **Сравнение периодов.** Четыре фиксированных режима: недели, дни недели, сезоны, годы. Дневные показатели или профиль целых суток. Настройки локальны этому модулю. Никаких пользовательских наборов, условий и конструирования графиков.
4. **Данные.** Импорт отчётов, наличие исходных картинок/точного расписания/сетки по датам, резервная копия и восстановление.

## Достоверность исходной тенденции

- media_scans хранит исходный PNG за дату ежедневного отчёта. 60-дневная история и недельная сетка не создают картинки за остальные даты. Отсутствующие картинки показываются явно; они не заменяются реконструированной линией.
- Привязка времени подтверждается по рамкам всех семи каналов и верхней/нижней границам на изображении. На 23 исходных отчётах: 1530×6036/6037, вертикальная шкала 5760 px за 24 часа (4 px/мин). Разница шапок в один пиксель учитывается. Неизвестный формат открывается как оригинал без привязки времени.
- При показе выбранного часа шапка со шкалой доли берётся отдельно из того же оригинала; масштаб линии не нормализуется между датами. Кадрирование не меняет значения.
- В Excel нет машиночитаемых поминутных значений этой линии. TOP содержит точные границы и средние показатели программ. Числа под изображением и в деталях явно подписаны как средние, их не выдают за замеры выбранной минуты.
- Картинки относятся к 18–54. Аудитория 25–34 доступна в дневном сравнении; линии из 18–54 не используются для неё.

## Данные и публикация

IndexedDB и схема остаются прежними. Новые простые настройки хранятся отдельным ключом, старые исследования сохранены для будущей версии, но не загружают текущий интерфейс. Резервная копия включает три числовых хранилища и настройки; картинки добавляются повторным импортом Excel.

Рабочие версии публикуются в существующий Sites. GitHub — только по отдельной прямой команде пользователя.
